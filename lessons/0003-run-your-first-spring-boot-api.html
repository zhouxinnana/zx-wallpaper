LESSON 0003 · 15 MINUTES

先跑通 API，再接数据库

第一个目标不是“搭好完整后端”，而是验证请求、响应和业务规则确实在服务端工作。为此，先用内存存储，把数据库这个变量暂时拿掉。

最小工程

在 Spring Initializr 创建一个 Maven、Java、Spring Web 项目。选择当前稳定的 Spring Boot 默认版本即可。下载并解压后，保留启动类，把下面三个文件放到同一个功能包中：

src/main/java/com/example/wallpaper/favorite/
  FavoriteController.java
  FavoriteService.java
  FavoriteResponse.java

按功能聚合比一开始建立全局 controller/、service/、repository/ 文件夹更容易看清一个功能的全貌。应用很小时，两种方式都能工作；这里选前者是为了让边界离需求更近。

服务：暂时用内存表达规则

package com.example.wallpaper.favorite;

import java.util.HashSet;
import java.util.Set;
import org.springframework.stereotype.Service;

@Service
class FavoriteService {
  private final Set<Long> favoriteWallpaperIds = new HashSet<>();

  FavoriteResponse add(Long wallpaperId) {
    boolean added = favoriteWallpaperIds.add(wallpaperId);
    return new FavoriteResponse(wallpaperId, added);
  }

  void remove(Long wallpaperId) {
    favoriteWallpaperIds.remove(wallpaperId);
  }
}

Set 天然不会保存重复 ID，所以它用于演示“重复收藏不会创建第二份数据”。这是教学替身，不是生产持久化方案：应用重启后数据会消失，也还没有多用户能力。

Controller：把 HTTP 映射到命令

package com.example.wallpaper.favorite;

import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/wallpapers")
class FavoriteController {
  private final FavoriteService service;

  FavoriteController(FavoriteService service) {
    this.service = service;
  }

  @PostMapping("/{wallpaperId}/favorite")
  ResponseEntity<FavoriteResponse> add(@PathVariable Long wallpaperId) {
    FavoriteResponse result = service.add(wallpaperId);
    HttpStatus status = result.created() ? HttpStatus.CREATED : HttpStatus.OK;
    return ResponseEntity.status(status).body(result);
  }

  @DeleteMapping("/{wallpaperId}/favorite")
  ResponseEntity<Void> remove(@PathVariable Long wallpaperId) {
    service.remove(wallpaperId);
    return ResponseEntity.noContent().build();
  }
}
package com.example.wallpaper.favorite;

record FavoriteResponse(Long wallpaperId, boolean created) {}

record 是适合小型不可变数据载体的 Java 写法。Spring 会把它序列化为 JSON。先把“当前用户”和“壁纸存在性”留空，下一轮再逐一补入；不要伪造认证或数据库来制造完整感。

启动与验证

./mvnw spring-boot:run

curl -i -X POST http://localhost:8080/api/wallpapers/42/favorite
curl -i -X DELETE http://localhost:8080/api/wallpapers/42/favorite

Windows PowerShell 也可以使用 curl.exe。第一次 POST 返回 201，重复 POST 返回 200，DELETE 返回 204。这就是本课的完成证据。
