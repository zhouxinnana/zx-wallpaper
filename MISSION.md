# Mission: Vue to Java Full-Stack Architecture

## Why
Build the ability to deliver maintainable product features across Vue and Java as AI changes the implementation workflow. The goal is to move from a frontend-only role to independently owning a feature from interface through API and data.

## Success looks like
- Implement a small Vue + Spring Boot feature with clear frontend, backend, and database responsibilities.
- Explain and review architectural boundaries, including the code proposed by AI tools.
- Deploy and troubleshoot a complete application with tests and observability appropriate to its size.

## Constraints
- Starts with working Vue knowledge and Java syntax familiarity.
- Prefer small, concrete exercises over broad theory.
- Treat AI as an implementation and review aid, not as an architectural authority.

## Out of scope
- Premature microservices, Kubernetes, and distributed-systems design.
- Learning multiple frontend frameworks at once.
