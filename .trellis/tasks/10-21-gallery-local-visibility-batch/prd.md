# 统一图库：本地图可见性与批量治理

## Goal

让「用户自己添加的本地壁纸目录」里的图片在应用内可见、可筛选、可批量治理，与在线下载图享受同一套浏览与操作能力；同时保留在线来源管理与存储概览。

## 背景与证据

- 现状：壁纸目录行只有「路径 + 启用开关 + 可用 N 张 · 无效 M 张 + 打开目录 + 移除」，没有任何单张图片的展示；在线图库却有完整 grid（缩略图 / 分类筛选 / 分页 / 删除 / 设壁纸 / 来源追溯）。
- 真实使用数据（本机状态文件）：`D:\ZX Wallpaper\Online` 有 50 张图，其中 48 张进了切换队列，但这 48 张既不在 `onlineImages`（在线图库）、也没有任何列表能看到，`wallpaperHistory` 里也从未出现 → 存在「参与轮转但完全不可见」的图片。
- 单张图的「跳过 / 喜欢 / 删除」目前只能对「当前壁纸」或已进入「已跳过 / 喜欢」列表的图发起，用户无法在目录里看全貌、批量治理。

## Requirements

### R1 统一图库视图

把侧栏「在线发现」改造为「图库」，页面顶部提供来源切换：**全部 / 在线 / 每个已添加的本地目录**。停用的本地目录同样出现在来源列表，但需有明确标记。

### R2 本地图可见

选中来源后以 grid 展示图片：缩略图（复用现有 grid 档位与懒加载）、文件名、所属目录；若已有 AI 标签则显示分类角标；对当前壁纸 / 已跳过 / 已喜欢给出状态角标。

### R3 单张操作

每张图支持：设为壁纸、查看原图、喜欢 / 取消喜欢、在目录中显示、跳过、删除（移入系统回收站）。操作后列表原位更新，不跳页。

### R4 批量操作

支持多选（逐张勾选 / 全选当前可见 / 反选 / 清空选择），对选中集合执行：

- 批量跳过 / 批量取消跳过
- 批量喜欢 / 批量取消喜欢
- 批量删除（移入系统回收站）
- 设为壁纸：**选中多于 1 张时禁用**，仅单选可用

### R5 筛选

来源切换之外，保留文件名筛选与 AI 分类筛选（含「未分类」），筛选对当前来源生效。

### R6 保留在线管理能力

存储概览、抓取来源（含分类同步）、同步日志仍在这页可访问，以可折叠区域承载，不删除任何现有能力。

### R7 目录行入口

工作台壁纸目录行增加「查看 N 张」，点击进入图库并预先选中该目录来源。

## Constraints

- 删除必须走系统回收站并经确认对话框，禁止静默删除或永久删除（项目既有约定）。
- 不改变切换队列语义：候选池仍是扁平集合，顺序 / 随机规则不变；图库是浏览视图，不承诺「看到的即轮转集」。
- 本地目录可能包含上千张图，必须分页 + 懒加载，禁止一次性渲染全部卡片。
- 本地图与在线图字段不同（在线有来源 URL、下载时间、尺寸），卡片必须能同时表达，不得用假数据补齐。

## Non-goals

- 不做目录树、重命名、裁剪编辑、去重、相册、评分、标签手工编辑。
- 不做「按图库筛选结果切换」的队列作用域功能（另有独立需求）。
- 不改动在线抓取逻辑与去重口径。

## Acceptance Criteria

- [ ] 侧栏出现「图库」，进入后可见来源切换，包含「全部」「在线」及每个本地目录
- [ ] 选中某本地目录后，能看到该目录内全部受支持图片的缩略图，可滚动加载更多
- [ ] 工作台目录行「查看 N 张」点击后跳到图库且已选中该目录
- [ ] 勾选 3 张本地图 → 批量跳过 → 三张出现在「已跳过图片」列表，切换队列不再包含，当前壁纸不变
- [ ] 勾选 3 张 → 批量删除 → 弹出确认框且写明数量 → 确认后三张移入回收站并从图库消失
- [ ] 批量删除集合中包含当前壁纸时，删除后自动切换到下一张可用壁纸
- [ ] 选中 2 张及以上时「设为壁纸」不可点击；单选时点击生效并暂停自动切换
- [ ] 批量喜欢后，图片出现在「我的喜欢」页；批量取消喜欢后消失
- [ ] 停用目录在来源列表中带标记，其图片仍可浏览
- [ ] 千张级目录下首屏只渲染一页，滚动不出现卡顿或内存异常
- [ ] 在线图库既有能力（来源筛选、分类筛选、同步日志、存储概览）无回归
- [ ] `npm run test`、`npm run typecheck`、`cargo test` 全部通过
