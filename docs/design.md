# ZX Wallpaper 视觉设计文档

## 设计目标

ZX Wallpaper 面向希望管理本地壁纸库、保持桌面氛围稳定的 Windows 用户。首屏唯一任务是让用户快速确认当前壁纸，并完成切换、暂停、目录管理和显示偏好设置。

本次方向命名为「数字暗房」：把应用从普通设置页改成一个安静的壁纸工作台。当前壁纸是视觉中心；设置是右侧工具轨；目录是可扫描的素材库。界面不添加营销内容、虚构指标或与壁纸管理无关的模块。

## 设计概念

设计概念使用 Image Gen 生成，用于校准主屏构图、色彩、密度和组件气质。关键特征：

- 深蓝黑色的桌面暗房底色，避免常见的纯黑加荧光绿模板。
- 青色作为运行和主操作色，珊瑚色只表示暂停、删除等需要注意的状态。
- 当前壁纸预览占据工作台主要面积，设置区域保持紧凑。
- 使用 `CURRENT FRAME`、`SOURCE LIBRARY` 等等宽标签作为“档案/素材库”语汇，而不是装饰性徽章。
- 细边框、直角或 4px 圆角、角标线和等宽路径文字共同形成“画框与文件索引”的识别点。

## 设计令牌

### 色彩

| 令牌 | 深色值 | 用途 |
| --- | --- | --- |
| `--ink` | `#0F171E` | 页面底色 |
| `--rail` | `#111D25` | 左侧导航 |
| `--surface` | `#18262E` | 工作区面板 |
| `--surface-raised` | `#1E2F38` | 下拉框、次级控件 |
| `--text` | `#E6EEE9` | 主文字 |
| `--muted` | `#8FA3AA` | 辅助文字、路径 |
| `--cyan` | `#68D4D0` | 运行态、主操作、焦点 |
| `--coral` | `#F28B72` | 暂停、危险操作 |
| `--sand` | `#F2D3A0` | 暂停状态文字 |

浅色主题复用相同语义令牌，通过 CSS 变量切换为清爽的灰白底和青绿色边界，不改变信息层级。

### 字体

- 标题：`Arial Narrow` 优先，回退到 `Segoe UI Variable`，形成略窄、清晰的工作台标题。
- 正文和控件：`Segoe UI Variable` / `Microsoft YaHei UI`，保证 Windows 中文显示稳定。
- 文件名、路径、版本号和结构标签：`Consolas`，强化本地文件与档案感。

### 尺寸与几何

- 页面左右内边距：桌面使用 `clamp(24px, 4vw, 64px)`。
- 面板间距：`16px` 或 `22px`，避免连续卡片堆叠。
- 面板边框：1px；常规圆角 0px，控件最多 4px。
- 主预览最小高度：`238px`，保证画面稳定，不因文案或按钮变化跳动。
- 响应断点：`980px` 开始上下排列；`700px` 切换为移动端顶部导航。

## 组件与状态

- `CurrentWallpaper`：当前文件名、预览、路径、暂停和立即切换。
- `SectionHeading`：图标、标题和真实的设置顺序编号。
- `SelectField`：切换间隔、显示方式。
- `ToggleRow`：开机启动、跟随系统主题。
- `FolderRow`：目录序号、目录名、路径、启用状态、开关、移除操作。

所有按钮保留明确动作文案；仅用于工具操作的图标按钮使用 `title` 与 `aria-label`。开关使用 `role="switch"` 和 `aria-checked`，并保留键盘焦点样式。

## 动效与可访问性

- 预览图仅做轻微 hover 缩放，强调它是可观察的当前状态。
- 操作按钮按下时下移 1px，避免添加无意义的持续动画。
- 加载状态使用旋转图标；`prefers-reduced-motion: reduce` 时关闭过渡与旋转。
- 对比度优先于装饰，浅色与深色主题都保留清晰的文字、边框和状态颜色。

## 浏览器演示状态

浏览器预览使用本地 API 模拟两条壁纸目录、128 张可用图片和一张实际可加载的远程风景图，让视觉验收能够覆盖“有内容”状态。真实 Electron 环境中，`window.zxWallpaper` 优先级更高，页面仍显示用户本地目录和当前壁纸。

## 验收标准

- 首屏能够同时看见当前壁纸、自动切换设置、偏好设置和壁纸目录。
- 暂停、立即切换、添加目录、目录开关、移除目录、下拉框和主题跟随均能更新界面状态。
- 980px 以下不出现横向溢出；700px 以下导航、预览操作和目录行仍可用。
- 深色主题不再使用绿色主色；浅色主题保留同一套青色识别系统。

## 已知环境限制

- `npm run typecheck` 和 `npm run build` 均通过。
- `npm run dev` 的 Electron 子进程因本机 `node_modules/electron` 安装不完整而退出；前端通过独立 Vite 服务完成了浏览器验收。修复 Electron 依赖后，页面会继续使用现有 `window.zxWallpaper` 生产桥接，不需要调整本次 UI 代码。
- Image Gen 概念图用于视觉方向校准，内置图像工具在本次会话中未返回可落盘的项目路径；因此未把概念图作为运行时资产提交。浏览器演示状态使用可加载的远程风景图，真实 Electron 环境仍优先展示本地壁纸。
