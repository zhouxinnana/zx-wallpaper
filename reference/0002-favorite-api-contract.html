收藏 API 契约速查

项目定义
请求POST /api/wallpapers/{wallpaperId}/favorite
身份由认证上下文取得当前 userId；不要信任客户端传来的 userId。
成功201 Created，返回新建收藏的标识或资源表示。
不存在404 Not Found，壁纸不存在时返回。
重复先定义产品语义：可返回既有结果（幂等），或返回 409 Conflict。第一版必须选定一种并测试。
唯一性数据库对 (user_id, wallpaper_id) 建唯一约束；Service 在该约束之上实现业务语义。

来源：Spring REST 服务指南、Spring Data JPA Reference
